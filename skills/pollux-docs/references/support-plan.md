# Support Plan — structure and rules

Output: **PDF, Paper mode, 1–2 pages**. Monthly managed support proposal (PolluxData Care).

Ref format: `SP-YYYY-NNN`.

## Required inputs

- Included services (5–6 bullets)
- SLA matrix: severity / example / response time
- Monthly scope table (hours, reviews, channels)
- Monthly fee + tax
- Payment terms, conditions (permanencia, horas, consumos)

## Structure

```
[BAND 64mm] title ("PolluxData Care — ...") + client
[01 — QUÉ INCLUYE EL PLAN]
[02 — ACUERDO DE NIVEL DE SERVICIO]  SLA table
[03 — ALCANCE MENSUAL]               table
[04 — INVERSIÓN MENSUAL]             totals block (single line + IVA)
[05 — CONDICIONES]                   bullets
[06 — ACEPTACIÓN]                    paragraph + signature block
```

## Rules

- SLA response times must be committed values, never "lo antes posible"
- Monthly fee uses the same totals block as offers (Subtotal/IVA/TOTAL)
- Signature block from common (two separate signature lines, never one continuous rule)
- Mascot: never

## Verification

- [ ] TOTAL = fee + IVA, correct
- [ ] SLA table has 4 severity levels with concrete times
- [ ] Permanence and extra-hours conditions explicit
