# Service Sheet (one-pager) — structure and rules

Output: **PDF, 1 page, Paper mode**. Sales sheet for a single service: fast to read, no client-specific data.

Ref format: `FS-<código>-<año>` (e.g., `FS-OCI-2026`).

## Required inputs

- Service name, one-line "what it solves"
- 4–6 bullet "what's included"
- Deliverables table (3–4 rows with timing)
- "From" price + disclaimer
- Contact

## Structure

```
[COMPACT BAND 56mm]
  Kicker "FICHA DE SERVICIO" · ref (no Ref prefix) · date
  Service title (white, 14pt) · star right

[01 — QUÉ RESUELVE]     1–2 sentences, pain-focused
[02 — QUÉ INCLUYE]      4–6 bullets
[03 — ENTREGABLES Y PLAZOS]  table (entregable / plazo)
[04 — INVERSIÓN]        "Desde USD X" big orange + disclaimer
[CTA]                   contact line
```

## Rules

- No client block in the band (generic sheet) — client name appears nowhere
- Mascot: never. Star yes
- Big price uses dedicated style (large leading) — never inline size in body style
- Must fit one page with breathing room; if it doesn't, cut includes, not margins

## Verification

- [ ] One page, no orphan heading
- [ ] Price doesn't collide with caption
- [ ] Star position matches proforma compact band (right side, small)
