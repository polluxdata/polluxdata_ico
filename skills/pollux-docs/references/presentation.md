# Commercial Presentation — structure and rules

Output: **PPTX, 16:9**. Two visual modes combined: **Dark cinematic cover + closing**, **Paper mode interior**.

It is the companion of an offer (`OF-YYYY-NNN`): same content, meeting format. Reuse the offer's numbers — never diverge.

## Slide structure (8)

1. **Portada (dark)** — navy band full slide, logo top-left, kicker orange spaced, title, client + date, mascot image (dark scene) occupying right half
2. **Resumen ejecutivo (paper)** — 3–4 bullets, large text, orange accents
3. **Contexto y objetivo (paper)** — short paragraph + goal bullets
4. **Alcance (paper)** — two panels: "Incluye" / "No incluye"
5. **Plan de trabajo (paper)** — phases table (navy header, zebra)
6. **Inversión (paper)** — pricing table + TOTAL in orange + payment note
7. **Por qué PolluxData (paper)** — 3 value cards (soft panels)
8. **Siguientes pasos (dark)** — CTA + steps + contact + logo

## Rules (from pollux-brand)

- Dark slides: bg `#06111F`, white Manrope titles, orange `#F07A1F` kicker
- Paper slides: white bg, navy headings, orange number + thin rule per section
- Mascot: cover only (dark scene assets blend here), never inside content slides
- Partner colors only on the partner-relevant slide if mentioned in the solution
- Tables: navy header, zebra `#F6F7FB`, numbers right, TOTAL orange
- Numbers must match the linked offer exactly

## Variables

Same inputs as the offer plus: `value_props` (3 short cards), `cta_steps` (3 steps).

## Verification checklist

- [ ] Totals identical to the offer
- [ ] Mascot only on cover
- [ ] No placeholder text
- [ ] Every slide has consistent margins and footer (interior slides)
- [ ] Tone: informal-ganadora, direct
